# 몰아보기 플래너

영화관·영화제 상영 시간을 직접 입력해 상영관별 시간표로 모아 보고, 볼 영화를 담으면 시간이 겹치는지 알려주는 페이지입니다.
파일 하나(`index.html`)로 동작하며 서버가 필요 없습니다. 입력한 내용은 사용하는 브라우저에만 저장됩니다.

## GitHub Pages로 공개하기

1. GitHub에 로그인 → 오른쪽 위 **+** → **New repository**
2. Repository name에 `marathon-planner` 입력, **Public** 선택 → **Create repository**
3. 새 저장소 화면에서 **uploading an existing file** 클릭
4. `index.html`과 `README.md`를 끌어다 놓고 → 아래 **Commit changes**
5. 저장소 상단 **Settings** → 왼쪽 **Pages**
6. Source: **Deploy from a branch**, Branch: **main** / **/(root)** → **Save**
7. 1~2분 뒤 `https://<GitHub 아이디>.github.io/marathon-planner/` 에서 열립니다

## 구글 시트에 저장하기

1. 구글 드라이브에서 **새 스프레드시트**를 만들고 이름을 정합니다 (예: 몰아보기 플래너 데이터)
2. 시트 메뉴 **확장 프로그램 → Apps Script**
3. 기본으로 있는 코드를 모두 지우고 `apps_script.gs` 내용을 붙여넣습니다
4. 맨 위 `SECRET` 값을 나만 아는 문구로 바꿉니다 (예: `jin-movie-2026`) → 💾 저장
5. 위쪽 함수 선택 칸에서 **setup** 선택 → **▶ 실행** → 권한 승인
   - "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동** → 허용
   - 시트에 `상영`, `저장기록` 탭이 생기면 성공
6. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
   - **배포** → 나오는 **웹 앱 URL** 복사 (`https://script.google.com/macros/s/.../exec`)
7. GitHub에 올린 플래너 페이지에서 **구글 시트 연결**을 열고
   - 웹 앱 주소: 복사한 URL
   - 비밀 키: 4번에서 정한 문구
   - **시트에서 불러오기** 클릭 → "연결됨"이 보이면 끝

이후에는 페이지를 열 때 시트에서 자동으로 불러오고, 영화를 추가·수정·삭제하면 1~2초 뒤 시트에 저장됩니다.
`저장기록` 탭에는 저장할 때마다 시각·영화 수·회차 수와 그때의 전체 사본이 쌓입니다 (최근 300건).
예전 상태로 되돌리려면 그 줄의 사본(JSON)을 복사해 Claude에게 주면 붙여넣기용 표로 바꿔 드립니다.

**주의**
- Apps Script 코드를 고친 뒤에는 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**를 해야 반영됩니다. 이렇게 하면 URL이 바뀌지 않습니다.
- 시트의 `상영` 탭을 직접 고쳐도 됩니다. 페이지를 새로고침하거나 **시트에서 불러오기**를 누르면 반영됩니다. 날짜는 `2026-11-21`, 시간은 `10:30` 형식으로 적어 주세요.
- 웹 앱 주소와 비밀 키는 각 기기 브라우저에 한 번씩 입력해야 합니다.
- 페이지는 마지막 저장이 이깁니다. 두 기기에서 동시에 고치면 나중에 저장한 쪽이 남습니다.

## 수정할 때

저장소에서 `index.html` 클릭 → 연필 아이콘(Edit) → 고친 뒤 **Commit changes**.
또는 새 `index.html`을 다시 업로드하면 덮어씌워집니다. 반영까지 1~2분 걸립니다.

## 입력 형식 (붙여넣기)

엑셀·구글 시트에서 아래 순서의 열을 복사해 붙여넣습니다. 탭이나 쉼표로 구분합니다.

```
날짜        시작   끝     제목   극장·상영관      예매 링크(선택)
2026-11-21  10:30  12:21  하녀   서울아트시네마   https://...
```
